# Portfolio / 展示文案

XBuil is an integrated construction business management application designed to bring project operations, workforce management, payroll, contracts and financial reporting into a single bilingual interface. Drawing on construction project-management experience, the project translates field and office workflows into a React and TypeScript application with a browser-local demo profile and a separate Supabase hosted architecture.

XBuil 是整合式營建工程與企業管理應用，將工程現場、人員與薪資、合約及財務報表集中於雙語介面。以工程專案管理經驗為基礎，透過 React 與 TypeScript 將現場與辦公室流程轉化為數位工具，並區分瀏覽器本機展示與 Supabase hosted 架構。

## Demo sequence / 展示順序

Home → project list → project detail → salary overview → company monthly report → language switch → mobile viewport. Use fictional data only.
